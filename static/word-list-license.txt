Fivefold version-1 vocabulary and generator provenance
====================================================

Accepted guesses are derived from the English five-letter word list published
by Tab Atkins Jr. at https://github.com/tabatkins/wordle-list.

Local transformation: retain exactly five lowercase ASCII letters, uppercase
ASCII, deduplicate, and sort by ASCII code-unit order. This yields 14,855
accepted guesses. words.ts freezes the complete result; there are no runtime
network requests. The 1,211 answers are a manually curated subset of familiar
words, deduplicated and sorted in ASCII order. Answers favor familiar singular
nouns, verbs, and adjectives rather than obscure dictionary entries; accepted
guesses deliberately retain the source's broader vocabulary and inflections.

Generator version 1 (engine.ts)
-------------------------------
Inputs are exact JavaScript strings. No trimming, case folding, Unicode
normalization, locale operations, date lookups, or platform entropy is used.
Encode each UTF-16 code unit in low-byte, high-byte order (UTF-16LE with no BOM).
This specifies empty strings, astral characters, and lone surrogates exactly.

Start h = 2166136261 (FNV-1a's 32-bit offset basis). For every encoded byte b:
  h = ((h XOR b) * 16777619) modulo 2^32.
The multiplication uses Math.imul, not floating-point multiplication.
Then apply one xorshift32 step, in order:
  h = h XOR (h << 13)
  h = h XOR (h >>> 17)
  h = h XOR (h << 5)
Treat the result as an unsigned 32-bit integer. Select ANSWERS[h % 1211].
Left shifts and XOR have JavaScript's 32-bit bitwise semantics; >>> is a
zero-filling right shift. There is no persistent PRNG state. Seed hashing is
linear in the seed's UTF-16 length, followed by constant-time answer selection;
there is no scan or rejection loop over possible answers. This is a puzzle
selector, not a cryptographic random generator. Modulo reduction has the usual
negligible bias when 1211 does not divide 2^32.

The ordered answer array is part of the version-1 format. Changing its order,
contents, the seed encoding, or the selector requires a new generator version
and an explicit migration of the puzzle identity contract. Saved games use
{version: 1, guesses: string[], draft: string}; all letters are uppercase ASCII.
Duplicate guesses are permitted; guesses after a correct answer are not.
A completed six-guess or won game has an empty draft.
